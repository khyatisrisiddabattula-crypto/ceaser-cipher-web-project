⚠ Cryptographic Note

The Caesar Cipher is a historical classical cipher and is NOT considered secure for modern confidential communication. There are only 26 possible shifts, so an attacker can break any message instantly by brute-forcing every key.

Reference

About Caesar Cipher

  • What it is: a monoalphabetic substitution cipher where each letter is replaced by another letter a fixed number of positions away.
  • History: used by Julius Caesar around 58 BC to protect military correspondence, making it one of the earliest recorded encryption schemes.
  • Encryption: C = (P + K) mod 26 — shift each letter forward by the key.
  • Decryption: P = (C − K + 26) mod 26 — shift each letter backward by the same key.
  • Vulnerability: only 25 useful keys exist, so brute force and letter-frequency analysis break it in milliseconds.
